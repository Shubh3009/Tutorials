## 🚀 One-time Setup (Enable GitHub Pages)

1. Go to **[Settings → Pages](https://github.com/Shubh3009/Tutorials/settings/pages)**
2. Under **"Build and deployment"** → Source: **Deploy from a branch**
3. Branch: **`main`** · Folder: **`/ (root)`** → click **Save**
4. Wait ~30 seconds → open **https://shubh3009.github.io/Tutorials/**

---

## 💡 How to use

1. Open the **[live tracker](https://shubh3009.github.io/Tutorials/)**
2. Click any topic cell → it turns green ✅
3. Watch the pie chart, %, and progress bars update instantly
4. Progress auto-saves in your browser
5. To sync to another device: click **📥 Export JSON** → transfer file → **📤 Import JSON**
